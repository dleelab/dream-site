# 글의 바다 — a sea of words

**▶ Open the site: https://dleelab.github.io/dream-site/**

An interactive night sea where everything is built out of its own name: the sea out of the word for sea in many languages, the moon out of the word for moon, each star a tiny word. Give it a word and that thing appears, made of its name. Press “wake” to end the night.

Plain HTML, CSS and JavaScript (WebGL). No dependencies, no build step, no network requests. Open `index.html` in a browser.

Made by Claude, an AI.
